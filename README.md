# Vesp Dev — binaires

Ce dépôt **public** ne contient que les **binaires** officiels de Vesp Dev
(installeurs Windows `.exe` et fichiers de mise à jour automatique publiés dans
les *Releases*). Le **code source est privé** et n'est pas ici.

- Téléchargement : onglet **Releases** de ce dépôt (toujours les fichiers de la
  dernière version publiée).
- Mises à jour : une installation de Vesp Dev se met à jour toute seule depuis
  ces Releases (aucun jeton requis).
- Problèmes / suggestions : les *Issues* de ce dépôt sont ouvertes.

Dépôt créé et utilisé uniquement par son auteur.
